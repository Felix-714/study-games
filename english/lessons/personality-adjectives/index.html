🌼 園丁的性格花圃

Personality Adjectives · 分清相似性格字，唔好俾選項混淆

1. 六朵重點性格花

patient = 有耐性，不容易嬲
calm = 冷靜，遇到麻煩仍保持鎮定
caring = 關心別人、願意照顧人
attentive = 細心留意別人或細節
responsible = 有責任感，應做嘅事會做好
brave = 勇敢，面對危險仍肯行動

2. 最易混淆

patient
重點：等得、唔易嬲
The gardener waits quietly.
calm
重點：緊急時保持鎮定
The gate suddenly closes, but Chelsea stays calm.
caring
重點：關心及照顧別人
The doctor checks an injured teammate.
attentive
重點：留意細節
The gardener notices one missing flower pot.

3. 園丁三步判斷法

  1. 先搵情境入面嘅動作
  2. 問自己：「係耐性、冷靜、關心、細心、責任，定勇敢？」
  3. 唔好只揀「聽落正面」嘅字，要揀最精準嗰個

例：角色走入危險房間救隊友 → 重點係面對危險 → brave。

4. 情境例子

  • Waits for a child to finish speaking → patient
  • Does not panic during an emergency → calm
  • Helps a sick friend → caring
  • Notices a small mistake → attentive
  • Finishes duties on time → responsible
  • Faces danger to help someone → brave

5. 花圃小測

The gardener notices that one tiny clue is missing from the table. Which adjective fits best?
